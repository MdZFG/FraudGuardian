# FraudGuardian 🛡️

FraudGuardian is an Android cybersecurity app designed to protect users—especially elderly and vulnerable individuals—from common phone-based frauds like OTP scams and unknown caller threats.

## 🚀 Features

* OTP Detection & Warning
* Unknown Call Alert System
* SOS Auto Alert to Trusted Contacts
* Voice Guidance (Text-to-Speech)

## 🎯 Purpose

To provide simple, real-time protection against everyday fraud attempts through intelligent alerts and automation.

## 🛠️ Tech Stack

* Kotlin (Android)
* Room Database
* SMS & Call APIs
* Text-to-Speech (TTS)
